# Tela de Login

Projeto de estudo feito com **HTML e CSS**: uma tela de login moderna, com efeito de vidro (glassmorphism) sobre um fundo em degradê com estrelas.


## Tecnologias

- HTML5 (formulário, campos obrigatórios, checkbox)
- CSS3 (Flexbox, degradê, `backdrop-filter`, transições e `:hover`)
- Google Fonts (Bangers) e Boxicons (ícones)

## O que pratiquei

- Montar um formulário com `input`, `label`, `button` e validação `required`
- Centralizar elementos com Flexbox
- Posicionar ícones dentro dos campos com `position: absolute`
- Criar efeito de vidro com transparência e desfoque
- Animar o botão com `transition` e `:hover`
- Organizar o CSS por seções e comentar o código

## Como rodar

Baixe o projeto e abra o arquivo `index.html` no navegador.
